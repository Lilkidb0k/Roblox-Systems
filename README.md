# Roblox Systems

A collection of reusable systems for Roblox developers, built with Luau and Roblox Studio.

My goal is to create practical, modular systems that developers can download, learn from, and integrate into their own games.

## 📦 Current Systems

| System | Description | Status |
|---|---|---|
| Round & Map Voting System | Multiplayer map selection, map loading and vote tracking | In development |

## 🚀 How to use

1. Browse the system folders in this repository.
2. Open the system's README to review its features and requirements.
3. Download the project file or source code.
4. Follow the installation instructions.
5. Test the system in Roblox Studio before using it in your game.

## 🛠️ Development

Systems are designed to be modular and configurable where practical.

Each system may include:
- A standalone Roblox Studio project
- Luau source code
- Setup and configuration instructions
- Example usage
- Known limitations and requirements

Check each system's documentation for its specific dependencies.
