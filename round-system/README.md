# Map Voting & Round System

A reusable map voting & round system for Roblox multiplayer games.

## ✨ Features

- Configurable map options
- Vote counting and live updates
- Voting countdown
- Random selection when multiple maps tie
- Configurable number of maps to vote on

## 📁 Project Structure

The source code and example project will be organized in this folder.

## 📋 Requirements

- Roblox Studio
- [**Trove**](https://sleitnick.github.io/RbxUtil/api/Trove/)
- [**Quinit**](https://github.com/DonkableDoof/Quinit/tree/main)
